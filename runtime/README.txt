Runtime files are generated locally and are intentionally excluded from Git.

Typical files generated by `python main.py export ...` include:
- openlca_catalog.json
- openlca_catalog_metadata.json
- process_reference_units.json
- process_gwp_snapshot.json
- process_gwp_snapshot_metadata.json
- payload_manifest.json
- Qwen_Colab_Payload.zip

Upload `Qwen_Colab_Payload.zip` to the guarded Colab runner. The payload is hash-verified before use.
